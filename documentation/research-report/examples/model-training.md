# 모델 학습 결과 예시

요청에 제공된 35B calibration 비교 요약을 사용한다. 원본 점수, 데이터셋별 전체 건수, run ID는 제공되지 않았다.

## 작성 전

두 테스트셋에서 ECE와 오류 AUROC가 개선됐다. 정답 검수는 296건, 714건 줄고 오답 승인은 33건, 128건 늘었다.

## 작성 후

**기존 승인 임계값 0.8에서 신규 모델 도입을 보류한다.** 검수가 필요한 정답은 줄었지만 두 평가셋 모두에서 오답을 더 많이 승인했다.

| 기존 모델 대비 변화 | BCB | NEB |
| --- | ---: | ---: |
| ECE (↓) | 감소 | 감소 |
| 오류 AUROC (↑) | 증가 | 증가 |
| 정답 검수 (건 ↓) | −296 | −714 |
| 오답 승인 (건 ↓) | +33 | +128 |

건수는 임계값 0.8에서의 차이다. ECE는 confidence와 실제 정답률의 일치 정도를, 오류 AUROC는 오류를 구별하는 순위 성능을 요약한다. 두 지표의 개선만으로 현재 운영 임계값의 승인 품질을 보장할 수 없다.

다음 비교에서는 검증셋으로 임계값을 정한 뒤 독립 평가셋에서 동일한 오답 승인율을 목표로 정답 검수량을 비교한다. 이를 위해 승인율의 분모와 모델별 원본 건수를 확보한다.

## 개선 이유

절대 점수가 없는 지표는 방향만 표시했다. 운영상 이득과 손실을 같은 표에 배치해 다음 임계값을 무엇으로 판단할지 드러냈다.
