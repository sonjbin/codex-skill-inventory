# 추론 최적화 예시

요청에 제공된 설명용 처리 시간(초)을 사용한다. 원본 run, 반복 횟수, 분산은 제공되지 않았다.

## 작성 전

기본 MTP는 2.417, 6.550, 9.593초, Shortlist는 2.521, 6.392, 8.424초, GQA와 Shortlist를 함께 쓰면 2.451, 5.995, 7.452초였다.

## 작성 후

**긴 표의 후속 검증에는 GQA + Shortlist 조합을 우선한다.** 30행 이상에서 기본 MTP 대비 처리 시간이 22.32% 줄었지만 1행에서는 기본 MTP가 가장 빨랐다.

기본 MTP의 초안 생성 비용을 줄이기 위해 후보 어휘를 4,096개로 제한한 방식(Shortlist)과 여기에 grouped-query attention(GQA)을 함께 적용한 방식을 비교했다.

| 표 크기 | 기본 MTP (초 ↓) | Shortlist (초 ↓) | GQA + Shortlist (초 ↓) |
| --- | ---: | ---: | ---: |
| 1행 | **2.417** | 2.521 | 2.451 |
| 10행 | 6.550 | 6.392 | **5.995** |
| 30행 이상 | 9.593 | 8.424 | **7.452** |

전체 트래픽에 적용할지는 행 수별 요청 비중과 반복 측정 편차를 확인한 뒤 결정한다. GQA 자체의 기여도를 판단하려면 GQA 단독 조건도 필요하다.

## 개선 이유

같은 행 수에서 세 방식을 가로로 읽을 수 있다. 짧은 표의 역전과 단독 대조군 누락을 밝혀 결론의 적용 범위를 정했다.
