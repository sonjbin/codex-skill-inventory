# 모델 학습 결과 예시

요청에 제공된 35B calibration 비교 요약을 사용한다. 원본 점수, 데이터셋별 전체 건수, run ID는 제공되지 않았다.

## 작성 전

두 테스트셋에서 ECE와 오류 AUROC가 개선됐다. 정답 검수는 296건, 714건 줄고 오답 승인은 33건, 128건 늘었다.

## 작성 후

**검수 없이 답을 승인하는 점수 기준을 0.8로 유지한다면 새 모델 도입은 보류한다.** 두 평가셋 모두 사람이 검수해야 하는 정답은 줄었지만, 새 모델이 그대로 승인한 오답은 늘었다.

| 기존 모델 대비 변화 | BCB | NEB |
| --- | ---: | ---: |
| ECE (↓) | 감소 | 감소 |
| 오류 AUROC (↑) | 증가 | 증가 |
| 정답 검수 (건 ↓) | −296 | −714 |
| 오답 승인 (건 ↓) | +33 | +128 |

건수는 승인 기준이 0.8일 때 기존 모델과 비교한 값이다. ECE는 모델이 예측한 정답 확률과 실제 정답률이 얼마나 가까운지 보여준다. 오류 AUROC는 오답에 정답보다 높은 오류 점수를 매기는 능력을 나타낸다.

다음 비교에서는 먼저 오답 승인율을 계산할 때 분모로 쓸 값과 모델별 원본 건수를 확인한다. 검증셋에서 두 모델의 오답 승인율이 비슷해지도록 각각의 승인 기준을 정한다. 별도 평가셋에서도 두 비율이 비슷한지 확인한 뒤, 사람이 검수해야 하는 정답이 어느 쪽에서 더 적은지 비교한다.

## 개선 이유

절대 점수가 없는 지표는 방향만 표시했다. “승인 품질을 보장할 수 없다”는 표현을 “새 모델이 그대로 승인한 오답은 늘었다”로 바꿨다. 어떤 결과 때문에 도입을 보류하는지 알 수 있다.
